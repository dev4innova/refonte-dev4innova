06 Méthode

Une méthode itérative qui livre de la valeur rapidement

Chaque étape réduit un risque avant d'investir dans la suivante. Après « Améliorer », on revient à « Explorer » avec ce que l'usage a appris.

  1. Explorer

    Ateliers avec vos équipes pour comprendre les enjeux, les données disponibles et les contraintes.

    Livrable : cas d'usage priorisés
